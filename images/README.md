# 圖片放置說明

將圖片放入本資料夾，檔名需完全一致（小寫）。重新整理後即可顯示；尚未放入時會維持淺灰色空白區塊。

| 圖片 | 檔名 | 建議尺寸 |
|---|---|---|
| 個人照片 | `profile.jpg` | 600 × 720 或更大，主體置中 |
| WWE-UIE | `papers/wweuie.png` | 800 × 600 |
| PromptHSI | `papers/prompthsi.png` | 800 × 600 |
| ChangeDINO | `papers/changedino.png` | 800 × 600 |
| 煞車碟裂縫偵測 | `papers/brake-disc.png` | 800 × 600 |
| 赤黴病偵測 | `papers/fusarium.png` | 800 × 600 |

如果要換副檔名（例如 JPG/WebP），請同步修改 `index.html` 中對應的 `data-image` 路徑。
照片會裁切填滿；論文圖片會完整顯示。
